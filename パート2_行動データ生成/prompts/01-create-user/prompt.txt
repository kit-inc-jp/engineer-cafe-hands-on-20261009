### 訪問するサイト

- 運営会社：素志社（そししゃ）。衣服、コスメ・ケア用品、生活雑貨、家具・寝具・収納用品、家電、食品を企画開発し、店舗とネットストアで販売する製造小売。
- 特徴：天然素材と肌馴染みの良い衣服、統一規格で組み合わせやすい収納・家具、日常の買い足しに向く品質と価格のコスメ・食品。簡素なデザイン。
- 価格帯：100円〜200,000円。主な客層は20代〜60代の男女、中間層。
- 商品カテゴリ：婦人・レディース、紳士・メンズ、バッグ・服飾雑貨、こども、コスメ・ケア用品、生活雑貨、家具、寝具、収納用品・収納ケース、家電・照明器具・時計、食品
- サイトには商品のほか、暮らしの読み物（ブログ）とお知らせ（新商品・キャンペーン・新店舗など）があります。

### 質問の進め方

- 1回に聞くのは **1〜3問**。各質問に3〜5個の選択肢（番号付き）と「その他（自由回答）」を付け、答えやすくする。
- 全体で **3〜5往復** を目安にし、行動を決めるのに必要な情報がそろったら終える。私が「おまかせ」と答えた項目は、それまでの回答と矛盾しない範囲であなたが決める。
- すでに答えた内容を聞き直さない。前の回答に応じて次の質問を変える。
- 年収・貯金・氏名・住所など、行動に不要な個人情報は聞かない。「節約したい」のような回答を勝手に金額へ変換しない。
- 選択肢には「買うつもりはない」「まだ決めていない」のような意向も含め、購入を前提にしない。

### 聞き出す情報

上から順に優先し、回答から分かったものは聞かなくてよい。

1. **どんな人か**：年代、暮らし方（一人暮らし・家族・子育て中など）、仕事や日中の過ごし方
2. **今回の訪問のきっかけと目的**：何を探しに来たか、ふらっと来たのか、買い足しか、プレゼントか、情報収集か
3. **今の状況**：訪問する曜日・時間帯、使う端末、急ぎ具合、気分や疲れ具合、使える時間
4. **判断基準**：価格・品質・素材・デザイン・読み物の情報など、何を重視するか。予算感（「1,000円以内なら気軽に」のように本人の言葉で）
5. **このサイトとの関係**：初めてか、何度か買ったことがあるか、ブログやお知らせを読む習慣があるか
6. **迷ったときのくせ**：すぐ決める、比較してから決める、カートに入れて保留する、など

### まとめと出力

1. 情報がそろったら、人物像を5〜8行で要約して見せ、「この人で行動ログを作ってよいか」を確認する。修正があれば直す。
2. 確定したら、次の形のJSONを **1つの ```json コードブロック** で出力する。ファイルを保存できる環境なら、`user.json` として保存し、そのパスも伝える。

```json
{
  "user_id": "sim-{YYYYMMDD}-{2桁の連番}",
  "nickname": "人物を表す短い呼び名（例：残業帰りの新社会人）",
  "persona": "人物像・今回の状況・訪問の目的を2〜3文で",
  "profile": {
    "age_group": "年代、または unknown",

    "visit_context": {

      "device": "スマートフォン / PC など",

```

- 回答から分からない項目は、それまでの回答と矛盾しない範囲であなたが決めるか、`unknown` にする。

出力したら「このJSONを user.json として保存してください。続けて行動ログを作る場合は、②のプロンプトを貼り付けてください」と案内して終わる。
